GolfQuest: The Ultimate Challenge Generator
GolfQuest is a 10‑week programming project designed to enhance group golf outings by generating unique challenges, scoring twists, and game modes. The application aims to make every round more engaging, competitive, and unpredictable. It is built using Python for the backend logic and HTML/CSS for the user interface.

Project Overview
GolfQuest transforms a standard round of golf into a dynamic challenge experience. For each hole, the application produces randomized tasks, modifiers, and scoring bonuses. It supports multiple game modes, group play, team scoring, and round history tracking.

The project combines game design, randomness, data handling, and user interaction into a single tool created specifically for golfers.
